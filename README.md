# LeetCode Solutions (Go)

A curated collection of LeetCode problems solved in **Go (Golang)**, focused on strengthening data structures and algorithms skills for coding interviews.

## 📌 About

This repository contains my personal solutions to LeetCode problems, all implemented in Go.  
The goal is to practice problem-solving, improve algorithmic thinking, and build a solid foundation for software engineering interviews.

## 🛠 Language

- **Go (Golang)**

## 📂 Structure

Problems are typically organized by:
- Problem number

Each solution includes:
- Clean and readable Go implementation
- Efficient time and space complexity where possible

## 🎯 Topics Covered

- Arrays & Strings  
- Hash Tables  
- Linked Lists  
- Stacks & Queues  
- Trees & Binary Search Trees  
- Graphs  
- Recursion & Backtracking  
- Dynamic Programming  
- Greedy Algorithms
